# 🎭 Emotion Detection with Deep Learning (BiGRU)

A deep learning Natural Language Processing (NLP) web app that predicts the emotional tone of text across 6 primary emotions:
- 😢 **Sadness**
- 😄 **Joy**
- ❤️ **Love**
- 😠 **Anger**
- 😨 **Fear**
- 😲 **Surprise**

### 🧠 Model Details
- **Architecture:** Bidirectional Gated Recurrent Unit (BiGRU)
- **Framework:** TensorFlow / Keras
- **Weights Repository:** [Nilaydawn/emotion-bigru-model](https://huggingface.co/Nilaydawn/emotion-bigru-model)
